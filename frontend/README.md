# Frontend

React/Vite frontend for the IEEE ITSS Conference Status Dashboard.

```powershell
npm install --registry=https://artifactory.iav.com/artifactory/api/npm/npm --cache D:\GitLab\agentic_webapp_ieee\creator-agent\workspace\npm-cache-local
npm run dev -- --host 127.0.0.1 --port 5191
```

The development server proxies `/api` requests to the FastAPI backend on port `8023`.
